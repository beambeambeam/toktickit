## Tool and model

- Coding agent: Codex in T3 Code
- LLM/model: GPT-5.6-Luna
- Account or platform: T3 Code
- Main use: planning, requirements clarification, issue preparation, implementation support, debugging, test review, and documentation review.

## Final brief reflection

The staged workflow improved prompt quality. First, grilling forced me to understand the lab sheet and identify hidden requirements before coding. Next, converting the plan into tickets gave each task a clear scope, dependency, branch, and acceptance criteria. Implementing one GitHub Issue at a time reduced scope drift and made testing more focused. The final review then separated working code from missing submission evidence. I still had to inspect and verify the generated code, tests, Git history, PR reviews, and documentation rather than accepting the AI output blindly.
